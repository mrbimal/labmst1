Q1 · 5 MARKS

Identity is not permission.

01

Authentication

Verifies who a user is, usually by checking credentials such as a password or a sign-in token.

02

Authorization

Determines what an authenticated user may do. For example, an Admin can delete a post while a Viewer can only read it.

03

JWT structure

A JSON Web Token has three Base64URL-encoded parts separated by dots:

HEADER.PAYLOAD.SIGNATURE

The header names the token type and signing algorithm; the payload contains claims such as subject, role, and expiry; the signature lets the receiver detect tampering and verify the token. A signed JWT is not necessarily encrypted, so its payload should not contain secrets.

For learning only: this client-side role switch demonstrates the interface. Real authorization must be enforced on a trusted server.
